A linux ricing project by landonslop

**Themes** : gruvbox, cozy log cabin aestheic, with hints of macos

## System
| | |
|---|---|
| OS | Debian 13 |
| Compositor | Niri |
| Desktop Bar | Dank Material Shell (DMS, Apparently renamed to Dux?) |
| Shell Runtime | Quickshell |
| x11 support | xwayland-satellite |
| Notifications | DMS (Built into DMS) |

## Niri binds
| Keys | Action |
|---|---|
| Mod+Q | kitty |
| Mod+D | Vicinae |
| Mod+E | Firefox |
| Mod+W | File manager |
| Mod+C | Close window |

------------------------------------------------------------------

## Distros

| | |
|---|---|
| Debian 13 | Tested working, a few of the apps must be built from source however |
| Arch Linux | Untested, Very high chance to work and work better than on Debian, less compiling because more apps are in official repos and/or AUR |
| Artix | Untested, Arch based so same repos + AUR. Very high change to work and work better than on Debian, but no systemd (Read Init) |
| Gentoo | Untested, Long compile times for qt are likely. High chance of working |
